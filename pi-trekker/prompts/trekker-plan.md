description: Draft a plan and optionally create Trekker tasks
argument-hint: '<goal>'
---

Use Trekker context to draft an implementation plan for: $ARGUMENTS

Steps:

1. Search related Trekker work first using a focused keyword.
2. Inspect active and ready tasks if relevant.
3. Draft a plan with goal, context, proposed tasks, files/areas, risks, acceptance criteria, and open questions.
4. Save the plan under the configured plans folder, default `docs/plans/`.
5. Provide a summary of the plan to the user.
6. Ask if user wants to be interviewed, change the plan or start creating Trekker epics/tasks/dependencies.
